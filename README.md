# API Node do Zero  
[![NPM](https://img.shields.io/npm/l/react)](https://github.com/Samyr-Dev/api-node-do-zero/blob/main/LICENSE)

# Sobre o projeto

Este projeto foi desenvolvido com o objetivo de aplicar, na prática, conceitos essenciais do desenvolvimento web moderno. Ele utiliza **Node.js** e **JavaScript** no back-end, com foco na construção de uma **API completa do zero**, integrando banco de dados e consolidando fundamentos de APIs REST.

Além disso, a estrutura do projeto está preparada para receber uma interface em **React**, permitindo evolução futura para um ambiente full stack com comunicação entre cliente e servidor.

O projeto foi construído a partir de estudos guiados e prática orientada, buscando simular demandas reais do mercado, como integração entre camadas, organização de código, versionamento e implantação.
