# Sobre o projeto

Sobre o projeto

Este projeto tem como objetivo aplicar na prática os conceitos de desenvolvimento web moderno, utilizando Node.js e JavaScript no back-end, e futuramente conectando uma interface em React para o front-end.

A aplicação foi desenvolvida com base em um projeto prático guiado, com foco em criar uma API do zero utilizando Node.js e Banco de Dados, consolidando conhecimentos em desenvolvimento de APIs REST e integração entre servidor e cliente.

Mais do que um simples exercício técnico, o projeto busca proporcionar uma experiência realista e completa de desenvolvimento full stack, unindo a lógica do servidor com a construção da interface do usuário.
